Football Skill Quest — Web App Game Prototype

วิธีเปิดใช้งาน
1) อัปโหลดโฟลเดอร์นี้ขึ้นบริการโฮสต์เว็บ เช่น Firebase Hosting / GitHub Pages / Netlify
2) เปิด index.html ผ่านเว็บเซิร์ฟเวอร์
3) บน iPhone/Android สามารถเพิ่มลงหน้าจอหลักได้เมื่อเปิดผ่าน HTTPS

ฟังก์ชันในเวอร์ชันนี้
- ภาษาไทย
- ตั้งชื่อนักเตะและหมายเลข
- รองรับสัมผัส/ลากนิ้วบนมือถือ
- ด่าน 1 เลี้ยงหลบกรวย
- ด่าน 2 เลี้ยงหลบกองหลัง
- ด่าน 3 ยิงประตูด้วยการปัดนิ้วขึ้น
- ระบบคะแนน เวลา และโบนัส
- PWA manifest + service worker
- ไม่ใช้ไลบรารีภายนอก
